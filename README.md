# academic-workflow-audit-skills
A collection of reusable skills for auditing academic manuscripts and revision packages. Covers manuscript checks before submission, response-letter audits, and consistency checks between reviewer responses and revised drafts.

## Available skills

- [Response letter audit](response-letter-audit/SKILL.md): Check reviewer coverage, numerical and cross-response consistency, the opening revision overview, and Word formatting. Export a structured, visually verified Word audit report.
